# Підготовка до деплою

## Вебзастосунок

1. Створити у Vercel проєкт із кореневою папкою `apps/web`.
2. Додати змінні з `.env.example` через налаштування Vercel.
3. Увімкнути автоматичний деплой із `main`.
4. Перевірити головну сторінку та production build.

## API

`apps/api` деплоїться окремим Vercel-проєктом у BIM-53. Вебклієнт отримує його URL через `NEXT_PUBLIC_API_URL`.

## Файли

DXF завантажуються напряму в приватний Supabase Storage через підписані URL. Це обходить ліміт тіла запиту Vercel Functions. У production не можна використовувати локальний диск для постійного зберігання файлів.

## Перед першим зовнішнім деплоєм

- погодити власника GitHub, Vercel і Supabase;
- додати всіх учасників команди;
- увімкнути захист `main`;
- виконати тест деплою коміту іншого учасника;
- перевірити, що секрети відсутні в історії Git.
