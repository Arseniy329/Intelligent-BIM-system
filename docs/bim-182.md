## API

Префікс `/api/v1`: GET `/drawings/{id}/zones`, POST `/rooms/{id}/zones`,
PATCH/DELETE `/zones/{id}`; GET/POST `/drawings/{id}/exits`, DELETE `/exits/{id}`.
Для виходу немає PATCH: редагування через прибирання та нове позначення.
Зони додаються багатокутниками по одній, залишаючись частинами кімнати.
Висота null дозволена сервером; інтерфейс явно пояснює недостатність даних.
Складні контури, допуски входження й перекриття перевіряє BIM-73;
клієнт перевіряє виродження/самоперетини й діапазон (0, 100].

  zoom/fit, перемикання режимів і типів приладів. Браузерний цикл запису зон/виходів

## Критерії та обмеження

| Критерій | Стан |
| --- | --- |
| Вибір кімнати, багатокутні зони, окремі висоти | Реалізовано |
| Зони належать одній кімнаті, збереження/скасування | Реалізовано; API та hook-тести |
| Геометрія, висота, помилки, повторні кліки | Клієнт + чинна серверна валідація; тести |
| Межі/висоти на плані, дані в таблиці | Реалізовано |
| Автоматичні виходи EXITS/«Вихід» | Чинний backend → GET → оверлей |
| Ручні виходи, повідомлення без виходів, повторний GET | Реалізовано |
| BIM-170 та точна відповідність BIM-131/BIM-129 | Не підтверджено |
| Наскрізний тест розгорнутого API/БД, merge | Не виконано |

У репозиторії знайдені старі fixtures Дениса та синтетичні API-тести; комплект
BIM-170 з таблицею очікуваного не знайдено, у Jira немає вкладень/посилання.
25.11 користувач надав 97 експортів PDF/SVG/JPG, усі проаналізовано. Еталон —
Desktop 6/10–19 та оригінальні SVG, не приблизне відтворення. Макети зон висоти
та евакуаційних виходів у комплекті відсутні; користувач дозволив продовжити.
Для цих нових станів застосовано структуру картки та кнопок із Desktop 10,
для вершин — квадратні маркери Desktop 11. Це розширення дизайну, не заявлена
точна копія відсутніх фреймів. Структуру workspace приведено до експортів,
але browser pixel-diff з тим самим кресленням і даними не виконано; тестовий
DXF відрізняється від зображеного в макеті. Точна відповідність залишається
відкритим критерієм. Вкладки правил/звіту не розширювалися (BIM-78 поза обсягом).
Прилади та оригінальна легенда — окрема BIM-122, а не залежність цієї гілки.

Серверні мутації зон/виходів не інвалідують попередній DXF результату. UI просить
повторити розміщення; після повторного відкриття сервер не віддає ознаку його
застарілості. Це обмеження BIM-73/BIM-75, алгоритми та API тут не змінено.

Ручна перевірка: у тестовому середовищі створити дві неперекривні зони з різними
висотами, спробувати перетин/вихід за контур; скасувати чернетку; перевірити
EXITS і «Вихід», додати ручний вихід, перезавантажити сторінку; повторити /place
й перевірити DXF. Перевірити масштабування, клавіатуру й вузький екран.
